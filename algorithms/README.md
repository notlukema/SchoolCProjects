# Tips

1. If over half of the tests are correct while a couple stay wrong, then it is likely that your code is missing something:
    - First, try rereading the instructions for any missed details (these can be very specific).
    - Next, search for any mistyped values.

2. If you are 100% sure of your algorithm but the results don't match, it is likely you have a hidden typo somewhere:
    - Mainly, reread any manually typed values.
    - If you can't find it for your life and it's a simple program, it might be better to just retype the entirety of the code since people can be surprisingly bad at finding typos of their own doing.

3. Sometimes, getting something to work first is most important:
    - Quickly throw togethor something that works, regardless of how messy the code is. After that, you should have a good standing ground for optimizing and cleaning up.
    - If any errors show up, you can easily identify them by reverting to the last working copy.
